# 意大利语 A2 词汇学习系统（Web 版）

供马可波罗计划生意大利语 A2 学习使用的本地词汇学习系统。

核心流程：手动抽取一批单词（默认 35 个，可配置）→ 学习后手动**标记完成**（完成后完成次数才 +1）→ 批次保留到背完为止，手动**换一批**时未完成的词自动保留进新批次 → 抽取算法优先覆盖**从未学过 / 完成次数少**的单词，尽量覆盖全部 1087 个 A2 词汇。

## 功能

- **学习模式**：背新单词。手动抽取批次（完成次数流转：零遍词优先覆盖全词库 → 完成次数少的词循环），卡片式学习，支持标记完成 / 撤销完成，顶部进度条；批次不按日期轮换，没背完的一直保留，点"换一批"才刷新（未完成的词保留进新批次）
- **测验模式**：间隔复习（SRS，Leitner 盒子法），与学习模式是两套独立体系——只测**到期复习词**（学习标记完成后的词次日到期），卡片只显示单词，点击翻转核对释义，答"认识"盒子 +1（上限 5，间隔 1/2/4/8/16 天），答"不认识"盒子归 0 明天再测；答过的卡片移出队列，全部答完显示本次成绩
- **拼写模式**：中→意产出复习，第三套独立体系（独立拼写盒子）。给中文释义拼出意大利语单词；不规则动词附加填写现在时 io 形式（conosco/viaggio）、不规则名词附加填写复数（lenzuola），单词 + 附加全对才升盒。判分自动（大小写、重音符号、空格容错）。防撞规则保证同一个词不会在同一天出现在测验和拼写两种模式里；刚学完/刚测过的词不会立刻进拼写队列
- **单词详情**：
  - 名词：单/复数定冠词（按词尾规则自动推断，含不规则复数如 uomo→uomini）、不定冠词（un / uno / una / un'）、性别
  - 动词：四时态变位表（现在时 / 近过去时 / 未完成过去时 / 简单将来时，各六人称；不规则动词内置表 + 规则模板 + 反身动词自动加代词）
  - 形容词：性数四格变化（-o 结尾四式、-e 结尾二式）
  - 例句：意大利语例句 + 中文翻译，手动编辑填充
  - 所有语法字段支持手动编辑补充
- **单词库**：1087 词，按分类（23 类）/ 状态 / 关键词筛选搜索，分页浏览
- **统计**：总词数、覆盖率、本批进度、累计完成次数、今日到期复习数、今日到期拼写数、已拼写词数、SRS 复习盒子分布与拼写盒子分布（进度条），分类分布与完成次数分布图表
- **设置**：每批抽取数量（默认 35）、冷却天数（默认 7）

## 数据库初始化

**无需手动建库建表**。数据库连接配置在 [backend/src/main/resources/application.yml](backend/src/main/resources/application.yml)：

- JDBC URL 带 `createDatabaseIfNotExist=true`：首次启动自动创建数据库 `italian_vocab`（utf8mb4）
- `schema.sql`（`CREATE TABLE IF NOT EXISTS`，幂等）自动建 4 张表：`word`、`word_progress`、`daily_extract`、`setting`
- 首次启动若 `word` 表为空，自动从 `backend/src/main/resources/data/vocab_data.json` 导入 1087 个单词（含自动预填的定冠词与动词变位）

如数据库账号密码不同，请在 `backend/` 下创建 `application-local.yml`（已被 .gitignore 排除，不会提交）：

```yaml
spring:
  datasource:
    password: 你的密码
```

或设置环境变量 `MYSQL_USERNAME` / `MYSQL_PASSWORD`。

## 启动方式

### 1. 启动后端（端口 8080）

```bash
cd backend
mvn spring-boot:run
```

启动日志出现 `自动导入完成：新增 1087 个` 即词库就绪。

### 2. 启动前端（端口 5173）

```bash
cd frontend
npm install        # 首次运行
npm run dev
```

### 3. 访问

浏览器打开 http://localhost:5173 （前端通过 Vite 代理转发 `/api` 到后端 8080，无需额外配置跨域）。

## 使用说明

1. 首次使用点"抽取第一批单词"开始学习；之后点"换一批"刷新批次（还有未完成的词时会先弹确认框，未完成的自动保留进新批次）
2. 学习后点卡片上的"标记完成"；误点可"撤销完成"
3. 标记完成的词次日进入"测验模式"：先回忆词义，点击卡片翻转核对，按"认识"或"不认识"（盒子归 0 明天再测）
4. 点击单词卡片查看详情：名词定冠词、动词变位；点"编辑"可补充/修改变位、定冠词、性别、释义
5. "设置"页可调整每批抽取数量与冷却天数（对下一次抽取生效）

## 抽取算法说明

点"换一批"（或首次抽取）时生成 N 个词的批次（N=每批数量），按**完成次数流转**：

1. **未完成的词保留**：上一批未标记完成的词直接进入新批次，学完为止
2. 剩余名额第一优先随机抽**从未抽取过**的词（第一遍覆盖全部词库）
3. 不足则抽**累计完成次数少**的词（次数升序 → 最久未抽优先；1 遍、2 遍循环，背完全库也有词可背）
4. **冷却期**：最近 `冷却天数` 内抽过的词不参与（避免连续重复）
5. 候选不足 N 个时放宽冷却限制补足

到期复习词**不进批次**——SRS 复习由测验模式接管（`next_review_at <= 今天` 的词全部出现在测验页）。

只有**标记完成后**该词的完成次数才 +1，撤销则 -1。未完成的词保持高优先级，冷却期后会被再次抽到复习。

说明：`extract_count` 字段的语义为**完成次数**（界面显示"已完成 N 次"）——单词仅被抽取而未标记完成时不计入，这样未掌握的词在冷却期后仍会被优先抽出，起到强制复习的作用；"最近抽取日期"则记录该词最近一次进入批次的时间。
